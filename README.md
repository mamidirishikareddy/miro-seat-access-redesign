## 🚩 The Problem

> Enterprise teams on Miro could add new seats **without admin approval** — creating unauthorized seat expansion, billing discrepancies, and weakened license governance.

<div align="center">

| 🔴 No Approval Gate | 🔴 Billing Discrepancies | 🔴 Governance Gaps |
|:---:|:---:|:---:|
| Seats added freely by any member | Enterprise plans over-billed unexpectedly | No visibility/control for admins |

</div>

---

## 🔍 Approach

<table>
<tr>
<td width="50%" valign="top">

### 🧩 Diagnose
- **Root Cause Analysis (RCA)** into how and why unauthorized seats were created
- Mapped stakeholders, workflows, and failure points across enterprise accounts

</td>
<td width="50%" valign="top">

### 🛠️ Design
- Proposed an **Admin Approval Workflow** to gate seat creation
- Structured into **3 features · 6 epics · 13 user stories**

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📊 Prioritize
- **RICE** to rank competing solution options
- **WSJF** to sequence the backlog by value vs. effort

</td>
<td width="50%" valign="top">

### 🚀 Roll Out
- Defined a **phased implementation roadmap**
- Minimized disruption to live enterprise workflows

</td>
</tr>
</table>
